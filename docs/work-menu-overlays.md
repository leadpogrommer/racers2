# Menu Manager and overlay records

This batch recovers the Menu Manager object and the record-list/text path it uses to create its 14 initial overlays. The manager requests allocation size `0x2b4`, uses game-object type `0x900`, allocates one record per descriptor, and releases them in reverse order before its base `Remove` call. The retail initializer leaves descriptor words 2 and 3 untouched; the source keeps those words uninitialized.

The overlay record pool uses a free-list root and 16 per-band list heads. `AllocateRecord` moves the free-list head into the requested band and copies the 13 descriptor words. `Release` clears the visible flag and first UTF-16 code unit, then returns the record to the free-list using its saved list ID. The list mover preserves the retail 200-node traversal limit, including its behavior of unlinking the node reached after the limit without a final value comparison.

The text path resolves indexed strings through `LocalizedStringTable::GetString`, decodes the overlay glyph replacement tables when configured, records replacement-glyph positions, and then calls the record’s width callback to apply horizontal alignment. The localized string table is an embedded game-controller object selected through the BSS pointer at `0x679b70`; that pointer is initialized to null until the controller startup path selects the language table. The glyph map is the existing manager field at `0x679b74` (`g_globalOverlayManager.m_unk0x2494c`), not separate storage.

The implementation is in [menumanager.cpp](../LEGO%20Racers%202/src/menumanager.cpp), [overlayrecords.cpp](../LEGO%20Racers%202/src/overlayrecords.cpp), and [localizedstringtable.cpp](../LEGO%20Racers%202/src/localizedstringtable.cpp). These functions remain `STUB` pending root’s integrated reccmp measurement. Raw extents are: `0x41c310` 214 bytes, `0x41c3f0` 6, `0x41c400` 30, `0x41c420` 11, `0x41c430` 148, `0x41c4d0` 40; `0x4b3470` 56, `0x4b34b0` 125, `0x4b38c0` 85, `0x4b3920` 33, `0x4b3980` 397, `0x4b3b10` 93, `0x4b3d40` 118, `0x4b78c0` 79, `0x4c4f30` 60, `0x4c50b0` 72, and `0x4c5110` 122 bytes. Extents include each full return instruction.
